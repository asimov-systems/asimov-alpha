## ⬇️ Installation

1. Download the latest, platform-specific zip file from this GitHub repository's [releases](https://github.com/asimov-systems/asimov-alpha/releases), to the right-hand side

2. Instruct your agent harness (e.g., Hermes, Claude Code, OpenClaw, etc.) to unzip the file and install the contents:

```
Install `asimov-alpha-0.1.0-macos-arm.zip` from the Downloads folder
```
