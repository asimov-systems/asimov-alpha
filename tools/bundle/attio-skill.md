## Attio module

The bundle includes the private `attio` module for Attio integration.
It supports reading people and companies from local Attio workspace exports.
Before using, run `asimov module doc attio` for examples and configuration.
Use `asimov list --limit=10 https://app.attio.com` to list records from the
newest Attio workspace export in your system's Downloads folder.
It is bundled locally only, not discoverable through the public module index.
